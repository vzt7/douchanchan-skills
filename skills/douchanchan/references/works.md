# Posts and data

## Preserve the target and scope

For a supplied post link, a current feed/detail post or an existing selection, operate that context directly. Do not navigate to a creator profile and discard the selection just to download one post.

For creator-data requests, use the supplied profile or the relevant current profile first. With only a nickname, locate the Douyin/TikTok profile and verify its identity; ask if multiple candidates remain. Search helps locate the profile, not supply its metrics.

Respect the requested tab, collection, search and date range. When the request refers to the current list, preserve its scope. For a newly opened profile with no requested scope, use publicly posted works. Clarify a missing time range only when it materially changes the result; do not assume all history.

## Read and filter

On a creator profile, click the floating entry to open results; right-click it to open the extension feature panel. When offered, its automatic-load action scrolls the current list to load more posts; click the running action again to stop.

Read loading progress from the source-info button by hovering or keyboard focus; clicking the source label does not reveal this tooltip. Distinguish loaded count from filtered count, and check whether more works remain, completeness is unknown or the cache is truncated.

Use available filters and sorting as needed. Date filters apply to loaded works; an older item does not prove the requested period is complete, especially under a non-chronological sort. Stop when coverage is established, the list ends, or loading no longer progresses. A truncated cache remains a partial sample even if the source reached its last page.

Use basic statistics or Data insights (Max) as requested. Keep missing metrics distinct from zero and retain displayed units and precision; rounded chart labels are not exact counts. Do not invent audience, revenue or other unavailable fields.

Deliver the requested data with a concise source/profile link, relevant time range, read time, sample count and coverage limitation. Reading visible basic data does not itself require Max. Follow the user's requested format; a data question does not automatically need a CSV export.

## Download or export

- **Single post:** use its download menu or expanded details to select the requested video quality, audio or image assets.
- **Multiple posts:** use Batch download with the intended selection and output settings. Directory output needs folder permission; ZIP output must finish archive generation. Verify saved files where tools permit and distinguish browser handoff from completed writes. Check partial output before retrying.
- **Post CSV (Max):** after sign-in and entitlement validation, open More actions > Data export, select posts and at least one available field group, then Export CSV. Confirm the output. If the entry is absent, check sign-in, Max and validation status; do not bypass export access by extracting internal caches.

Post CSV contains metadata and metrics, not media files or analysis reports.

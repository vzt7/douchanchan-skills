# Browser setup and recovery

Use the browser/profile the agent controls. If the extension is missing, install it from:

- [Chrome Web Store](https://chrome.google.com/webstore/detail/jlknbjboeobdnibieepdfbnlppgegilj)
- [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/ljlebognoljmahakfgkmbciigfmhjbde)

Use the chosen browser's tools, including accessible Shadow DOM when supported. Locate the floating results/menu button by its accessible label. It usually starts near the right edge; position, skin and opacity can vary.

If missing, check the controlled profile, extension enablement/site access and supported-page readiness. In the extension popup, use **Show floating window** or **Reset position** when enabled; disabled controls may mean no entry is mounted. If popup controls or required system permissions are inaccessible, ask the user. Refresh only when safe for ongoing recordings, uploads and selections; do not loop reloads.

If signed out, ask the user to sign in to Douyin/TikTok before downloading; downloads may otherwise fail.

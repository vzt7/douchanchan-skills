# Analysis and reports

Open [analysis tasks](https://douchanchan.toolspace.xyz/analysis-tasks). Sign in through the avatar menu.

## Submit analysis

- **Platform post:** use the extension's analysis action on that post.
- **Local video:** use **New analysis** on the website; no extension is needed.

Select the material, enter the user's requirements, and wait for the quote. Confirm only within the approved cost, then upload and retain the task ID. Track its status on the website; submission does not mean the report is ready.

For interrupted uploads, resume the existing draft or task and reselect the same file if prompted. Check its status before resubmitting to avoid duplicate charges.

## Read and export

Open the completed task's report. Summarize the relevant findings with evidence anchors and limitations.

| Format | Entry |
| --- | --- |
| Markdown | Report sidebar download |
| JSON | **Advanced export > JSON** |
| PDF or ZIP | **Advanced export**; requires Max |

Choose the requested format and available attribution options, then download and confirm the file.

## Share or manage

Reports start private. For an authorized share, open **Share report**, switch to **Public**, and copy the link. Anonymous shared reports are read-only.

Use the website's task/report controls for feedback, cancellation, or deletion.
